# 가이드 글 주제 순서표

매일 아침 예약 작업('빡세 세차 가이드 글 초안')이 **이 표의 위에서부터** 쓸 주제를 고릅니다. 공개 날짜는 표가 아니라 `python tools/guide_tools.py plan`이 정합니다.

- 만든 곳: 운영자 컴퓨터 Claude가 `docs/guide-keywords.md`(네이버 검색량, 2026-11-18 기준)를 보고 관련 검색어를 묶어 정리
- 순서를 바꾸거나 빼고 싶으면 운영자가 아침 초안 대화나 운영자 컴퓨터 Claude에게 말하면 됩니다
- 상태: `예정` → (운영자가 "올려" 승인하면) `올림 11/26 slug`. 승인 안 된 주제는 `예정`으로 남아 다음 날 다시 씁니다

- 검색량은 네이버 월간 검색량(PC+모바일) 합계예요. 묶은 말 중 다른 뜻으로도 검색되는 말(예: 가죽클리너는 소파·신발용도 포함)이 있어 대략적인 크기로만 봅니다
